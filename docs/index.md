# OpenSpec Workbench

OpenSpec Workbench is an unofficial, read-only local application for browsing
Git-reviewed OpenSpec plans across projects and existing worktrees. English
OpenSpec files remain authoritative; this site explains installation and
operation but never replaces repository planning artifacts.

The beta application binds only to loopback, registers projects explicitly,
and does not edit plans, switch branches, create worktrees, commit, or push.

## Documentation

- [Getting started](getting-started.md) covers Hub-first installation and recovery commands.
- [Security model](security.md) summarizes the local trust and capability boundaries.
- [Release operations](release-operations.md) defines documentation, CI, synchronization, tag, and release gates.

For contributor policy and complete implementation detail, use the repository
README, SECURITY policy, and Git-reviewed OpenSpec artifacts.
